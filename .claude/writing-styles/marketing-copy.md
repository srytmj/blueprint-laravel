# Writing Style: Marketing Copy

For public-facing pages, landing pages, README intros, announcements.

- Lead with the concrete outcome for the reader, not the feature list.
- Short sentences. Cut qualifiers ("very", "really", "simply") on sight.
- Confident, not hyped. No exclamation-point stacking, no "revolutionary"/"game-changing"/"seamless" unless it's true and specific.
- Second person ("you") over third person ("users").
- One idea per sentence. One argument per paragraph.
